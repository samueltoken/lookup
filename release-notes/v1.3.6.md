# lookup 1.3.6

- Improved webpage-to-PDF conversion for lazy-loaded images, scrolling areas, embedded frames, and tall images. Blank or blocked captures now report an error.
- Kept mouse-wheel scrolling within the current page when zoomed, with access to both edges of wide pages.
- Refreshed the interface with simpler tabs, controls, and conversion status. The supplied duck artwork now has a transparent background in the app and Windows icon.
- Fixed PDF saves and Korean annotations. Switching away from a modified document now prompts to save changes.
- Improved Excel rendering for large sheets, merged cells, formatting, and sheet navigation.
- Improved HWP/HWPX images, tables, paper sizes, page breaks, fonts, and colors. Rendering still depends on the document and available conversion tools.
- Added automatic cleanup of verified files, shortcuts, and stale file registrations from earlier lookup installations while preserving documents and settings.
- Fixed removal of the installer-created Start menu and desktop shortcuts during uninstall.
